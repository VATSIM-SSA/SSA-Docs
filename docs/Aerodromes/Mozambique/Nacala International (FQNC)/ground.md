# Ground

The responsibility of SMC at "Nacala International Airport" falls to the dedicated Ground ATS unit, "Nacala Ground" (FQNC_GND) on 121.700 or 121.900 MHz. SMC will be responsible for the aerodrome movements outside of the runway, including pushback and taxi to/from the runway. SMC will also be responsible for the initial call of VFR aircraft looking for start and taxi to the runway. 

## Visual Flight Rules (VFR) Aircraft.

On initial call with SMC, the VFR aircraft is expected to provide:

* Aircraft Registration, if the callsign used is not the aircraft registration
* Aircraft Type
* Persons on Board
* Fuel Endurance
* Intentions

Once this data has been received by the SMC controller, the controller shall then issue the QNH, Active Runway, and if operating on a FPL, a discrete squawk code.

!!! info "VFR Phraseology"
    "C9MPM, start up approved, Runway XX in use, QNH XXXX, report ready for taxi."


## Pushback Procedures

SMC controllers should remain vigilant at all times.


|Stand | Runway in use | Direction | Remarks |
| :---------: | :---------: | :---------: | :---------: |
| A1 - A4          | 01/19 | - | Taxi-out stands |
| C1 - C5, E1 - E2 | 01/19 | N | - |

!!! tip Specifying pushback direction in not required when issuing a pushback

!!! info "Pushback Phraseology"
    "(callsign), push and start approved, Runway XX , QNH (QNH)."

## Taxi Procedures

All aircraft should be taxied to holding point B for backtrack.
