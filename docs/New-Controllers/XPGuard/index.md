# XPGuard

XPGuard adds VATSIM-controlled airport ground lighting to pilots' simulators. A
controller sets the lights from EuroScope, and pilots see them in MSFS or X-Plane.

XPGuard offers several features. On VATSSA we currently use:

- **Stop bars**
- **Takeoff Hold Lights (THL)**
- **Runway Entrance Lights (REL)**

!!! info "Looking for the pilot setup?"
    This section is for controllers. If you fly on the network, see the
    [XPGuard guide in the Pilot's Corner](../../Pilot's%20Corner/Pilot%20Resources/XPGuard/) instead.

!!! warning "For VATSIM use only"
    Lights never replace an ATC clearance. Always control to your own clearances. A
    stop bar switching off does not by itself clear an aircraft to proceed.

## How it works

| Step | What happens |
| ---- | ------------ |
| 1 · Controller | You claim your runways and set the lights from the XPGuard EuroScope plugin. |
| 2 · XPGuard | Every change is sent to the pilots at that airport. |
